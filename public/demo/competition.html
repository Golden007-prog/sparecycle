Meet the balanced SpareCycle workflow

SpareCycle helps teams use the laptops they already have, and fix the diagnostic software behind them. This is a working prototype using synthetic demonstration records.

From planning to Pilot Operations

Workshop allocates declared parts, time and budget. Pilot Operations freezes a plan, records bench progress, actual effort and evidence checks, then exports a local handoff. Physical release still needs technician judgment.

Tavily research with Nebius synthesis

The Research desk calls Tavily for official documentation at runtime. NVIDIA Nemotron on Nebius summarizes bounded sources with checked citation IDs, uncertainties and next checks. Search does not approve a repair.

The organization, passport and parser failure

Organization access protects the Review workspace. This laptop's evidence records a concrete bug: a valid zero-percent battery reading is discarded as missing data.

Nebius hosts NVIDIA inference

Nebius Token Factory supplies actual NVIDIA inference. The server sends bounded requests, without exposing provider credentials to the browser.

Models have explicit stage roles

Lightning investigated this public case; Super wrote and freshly reviewed the patch. Nano and opt-in Ultra were separately exercised.

Recorded usage across four tiers

Recorded Nebius usage shows four tiers. These rounded cost buckets are not a per-change invoice or a quality benchmark.

The trusted AI harness

The harness enforces structured output, a forty-second model deadline and reserved spend. Models have no shell or publishing tools. Code and evidence hashes bind tests and approval; LangSmith records metadata.

One bounded parser candidate

The proposed change targets one pure JavaScript diagnostic parser. Existing tests and the repository version are pinned before execution.

Prove failure, then pass the same tests

Real GitHub Actions verification first reproduces the defect: three tests pass, one fails. The exact candidate then passes all four unchanged tests in an isolated container.

Separate approval for the exact change

A fresh model review examines the result. A different organization member approves the exact candidate. Changed evidence or code requires a new approval.

An actual draft pull request

The GitHub App creates this actual draft PR with its verification record. No automatic merge, deployment or physical-repair claim follows.

The separately verified private pilot

A separate private pilot also completed, using encrypted transport and a pinned verifier in its own repository, with separate human approval.

Review insights and attention queue

Review insights surface stale evidence, delayed jobs and work needing attention. They compare loaded record references; the server still decides which actions are allowed.

The investment gates remain visible

Google sign-in works. Company email, enforced SSO, shared inventory and broader language support remain investment gates. The two-hundred-capability map is planned work.
